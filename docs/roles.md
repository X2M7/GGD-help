# Steam 版角色目录

核对日期：2026-11-04。适用 Goose Goose Duck 的 Steam / 国际版 PC 客户端；不混入国服手游专属角色。代码目录位于 `native/RoleCatalog.cs`。

当前收录 **79 个可标记身份：好 34、中 11、坏 34**，包含普通鹅、普通鸭以及腐化模式角色。选择“好 / 中 / 坏”后，第二项只显示该阵营的具体角色。可以只确定阵营，把具体角色留为“待定”。

这是跨地图、跨经典 / 轮抽 / 腐化模式的记录工具，因此目录中的角色不代表同一房间都能选择。地图、房间开关、角色互斥和游戏模式仍以游戏内设置为准。

## 旧记录兼容

旧版简称会对应到完整名称，例如“加拿大 → 加拿大鹅”“模仿 → 模仿者”“观鸟 → 观鸟者”“隐形 → 隐形者”“食鸭鸟 → 食鸟鸭”“呆呆 → 呆呆鸟”。“好人 / 坏比”对应普通“鹅 / 鸭子”；原先的“中立”只保留阵营，具体角色设为待定。

同一角色的译名兼容包括“生存家 → 求生者”“默剧演员 → 哑剧演员”“迷途小鸭 → 走失小鸭”“新教徒 → 新信徒”。保留这些官方公告中出现的不同译法，避免同一角色在菜单中重复；未核实的直译名称不自动替换。未知的自定义角色名称仍保留，避免升级后丢失旧记录。
